## Протокол

- Backend — `gradlew.bat clean check bootJar` и повторный `check`. Проверка использовала Testcontainers и временный MEDIA_ROOT.
- Frontend — `npm ci`, `npm run lint`, `npm run lint:ci`, `npm run test:ci`, `npm run build`.
- Playwright — `npm run test:e2e`, выбор движка через `E2E_BROWSER`. Отдельная БД на запуск и четыре ширины окна.
- Git и CI — `git diff --check`, Commit Check и локальный `collect_metrics.py --require-complete`. Числа приведены в [HTML-отчёте](../reports/final-audit.html).
