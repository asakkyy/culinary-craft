Безопасность и исправления

  • Неподтверждённый ADMIN получает 403 на защищённых административных POST. Подтверждённый ADMIN выполняет разрешённые операции. Доступ USER ограничен сервером.
  • Смена email удаляет прежние токены в той же транзакции. Ссылки остаются недействительными после возврата к исходному адресу. Тесты подтверждают одноразовость и истечение срока.
  • Восстановленные исправления UI покрывают сохранение фильтров и пагинации после обновления, стабильную SQL-сортировку, фокус меню и диалогов, устаревшие ответы React и повторную загрузку после ошибок.
  • Проверены CSRF, атрибуты cookie, проверка JWT, отзыв сессии при блокировке и выходе. В DTO секреты скрыты, отправка почты выполняется после commit, токены хранятся как хеши.
  • Проверка сигнатур секретов в текущем коде и доступной истории совпадений не обнаружила. Обновление Vitest убрало две критические записи npm audit из тестовой цепочки.
  • Остались шесть записей high в dev-цепочке picomatch, включая зависимые пакеты. В production-цепочке остались две moderate по React Router. Проверены исходники перехода после входа. Приложение использует клиентский роутинг.
